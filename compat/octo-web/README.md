# Octo 客户端历史同步补丁

针对官方 [octo-web `7ace0e96`](https://github.com/Mininglamp-OSS/octo-web/tree/7ace0e96df36a2c03657178564c182fc23af6e25) 的独立审阅材料。**尚未合入、部署到正式 Octo，也未执行完整客户端 CI。** 此目录不随 DSH 插件安装包部署。

## 已复现的问题

文件消息已显示后，客户端发起历史同步。等待响应期间收到完整说明文字，随后旧历史快照覆盖实时列表，文字从列表消失；重新读取新历史后恢复。服务器正文并没有丢失。此源码复现与用户症状相符，但尚不能证明原现场使用了该版本或发生了同一请求时序。

[补丁](history-sync.patch) 为请求期间的新增消息建立临时记录，合并最新页而不拼回全部旧历史；重叠请求、历史定位、清空/卸载及旧分页回调按请求版本处理。去重优先采用服务端身份，保留删除/撤回状态；客户端消息号冲突不再误合并不同消息。改动 `Conversation/vm.ts`，新增 `historySnapshot.ts` 及其测试，并扩充原有 `messageOrder.test.ts`，共四个文件。

2026-11-10 整模块回归发现并修复旧补丁的一处回归：点击“回到最新消息”时，不再提前隐藏未读提示。滚动意图绑定到该次请求，只有确已取得最新消息才允许滚动；失败、空响应、落后响应及被后续请求取代时保留提示。
